# Docs-Keeper: tools

- Notion read/write (`owned: yes`; the reason Notion was chosen as the documentation home), including the Decisions Log database.
- `../memory/<repo>/docs/` read/write (`owned: no`). On `owned: no` it has no Notion access and never calls a Notion tool.
- Read access to the decision events from the councils, the Chief of Engineering and the QA lock of acceptance criteria.

No code write access.
